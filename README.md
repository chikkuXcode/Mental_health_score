# 🧠 Mental Health Score Prediction

A machine-learning web application that estimates a **mental health score** from selected lifestyle, academic, and social-media habits. The project combines a trained regression model with a FastAPI backend and a responsive HTML, CSS, and JavaScript frontend.

> **Live demo:** [Mental Health Score Prediction](https://mental-health-score-vbin.onrender.com)

> **Important:** This project is for educational and informational purposes only. Its output is a model prediction, not a medical diagnosis or a substitute for professional support.

---

## ✨ Features

- **Interactive web interface** for entering personal and daily-habit information.
- **Mental health score estimate** generated by a trained machine-learning model.
- **Input validation** for fields such as age, categories, and daily hours.
- **24-hour time budget** in the frontend to help keep tracked daily activities within a day.
- **REST API** built with FastAPI.
- **Data preprocessing pipeline** that applies scaling and categorical encoding consistently with model training.
- **API documentation** provided by FastAPI's Swagger UI.

## 🧾 Inputs used by the model

The prediction endpoint accepts these fields:

| Field | Description |
|---|---|
| `age` | User's age (10–100 in the API schema) |
| `gender` | `Male` or `Female` |
| `academic_level` | `High School`, `Undergraduate`, or `Graduate` |
| `most_used_platform` | Most-used social media platform |
| `purpose_of_use` | Main purpose of social media use |
| `avg_daily_usage_hours` | Average daily social-media usage, in hours |
| `daily_unlocks` | Number of phone unlocks per day |
| `study_hours` | Study hours per day |
| `physical_activity_hours` | Physical activity hours per day |
| `sleep_hours_per_night` | Sleep hours per night |
| `stress_level` | Self-reported stress level |

The frontend's daily time-budget check is a usability safeguard. As with any data-driven model, a plausible-looking score does not guarantee that the prediction is correct for an individual.

## 🤖 Machine-learning workflow

1. Load the Student Social Media and Mental Health Impact dataset.
2. Remove duplicate rows and inspect numeric distributions, correlations, stress-level relationships, platform counts, and outliers.
3. Correct negative physical-activity values by clipping them to zero.
4. Split the data into training and testing sets with a 70:30 ratio (`random_state=42`).
5. Build a `ColumnTransformer` pipeline:
   - `Study_Hours`: `log1p` transformation followed by `StandardScaler`.
   - Other numeric features: `StandardScaler`.
   - `Stress_Level` and `Academic_Level`: `OrdinalEncoder`.
   - `Gender`, `Most_Used_Platform`, and `Purpose_Of_Use`: `OneHotEncoder(handle_unknown="ignore")`.
6. Compare Linear Regression and Random Forest Regression.
7. Save the fitted Random Forest pipeline as `Mental_health_model.pkl` for use by the API.

### Model evaluation

The notebook reports the following results for the saved Random Forest pipeline on its 70:30 split:

| Metric | Training set | Test set |
|---|---:|---:|
| R² | 0.9796 | 0.8659 |
| RMSE | 0.1797 | 0.4853 |

R² describes how much variation in the target is explained on that split; it is **not** classification accuracy. Results may vary if the dataset, preprocessing, or split changes.

## 🚀 Run locally

### 1. Clone the repository

```bash
git clone (https://github.com/chikkuXcode/Mental_health_score)
```

### 2. Create and activate a virtual environment

**Windows PowerShell:**

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

**macOS / Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Use a Scikit-learn version compatible with the one used to save the `.pkl` file. The notebook's saved model was created with the project's Scikit-learn training environment; keeping training and serving versions aligned helps avoid model-loading errors.

### 4. Start the API

From the directory containing `main.py` and `Mental_health_model.pkl`, run:

```bash
python -m uvicorn main:app --reload
```

The API should be available at `http://127.0.0.1:8000` and interactive API documentation at `http://127.0.0.1:8000/docs`.

### 5. Open the frontend

Open `index.html` in your browser or serve the frontend folder with a local development server. Make sure `script.js` points to the correct API base URL. For local development, the prediction endpoint is usually:

```javascript
const API_URL = "http://127.0.0.1:8000/predict";
```

For a deployed frontend, change this to the deployed FastAPI backend's full `/predict` URL. If the frontend and backend have different origins, configure FastAPI CORS to allow the frontend origin.

## 🔌 API usage

### `GET /`

Returns a welcome message.

### `POST /predict`

Example request body:

```json
{
  "age": 22,
  "gender": "Male",
  "academic_level": "Undergraduate",
  "most_used_platform": "Instagram",
  "purpose_of_use": "Education",
  "avg_daily_usage_hours": 4.5,
  "daily_unlocks": 35,
  "study_hours": 5,
  "physical_activity_hours": 1,
  "sleep_hours_per_night": 7,
  "stress_level": "Medium"
}
```

Example response format:

```json
{
  "predicted_mental_health_score": 6.78
}
```

The number above is only an example of the response format; an actual score depends on the submitted input and the loaded model.
